# Data

SMS Spam Collection (Almeida & Hidalgo, UCI Machine Learning Repository), in the Kaggle `spam.csv` format
(columns `v1` = ham/spam, `v2` = message; latin-1 encoded): https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset

Place the file at `data/spam.csv`. It isn't committed here.
